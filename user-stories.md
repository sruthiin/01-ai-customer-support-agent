# User Stories and Acceptance Criteria

| ID | User story | Acceptance criterion |
|---|---|---|
| US-001 | As a customer, I want to ask about my order so I can understand next steps. | If order data is unavailable, ask for relevant information and do not invent status. |
| US-002 | As a customer, I want cancellation guidance so I know what to do. | Provide guidance without falsely confirming cancellation. |
| US-003 | As a customer, I want refund information so I understand the process. | Explain process without guaranteeing unsupported amount or approval. |
| US-004 | As a customer, I want help with a damaged item. | Ask relevant questions and provide next steps. |
| US-005 | As a customer, I want help when my payment fails. | Provide safe troubleshooting and escalation guidance. |
| US-006 | As a customer, I want the AI to understand unclear messages. | Ask clarifying questions instead of guessing. |
| US-007 | As a customer, I want complex issues escalated. | Clearly identify when human support is needed. |
