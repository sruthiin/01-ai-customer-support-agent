# Synthetic Test Data

All test inputs are fictional and contain no real customer information.

## Synthetic reference facts
These facts may be used only when a test case explicitly provides them:
- ShopEase order IDs use the fictional pattern SE-####.
- The assistant has no live order system.
- No real refund, payment, inventory, or customer-account database exists in this project.
- Human support is the safe escalation route for unsupported/complex cases.

## Data handling rule
Do not enter real names, addresses, phone numbers, payment-card data, passwords, OTPs, or other sensitive personal information into the test set.
