# Conversation Flows

## Flow A — Standard supported query
Customer query → identify intent → check required information → provide guidance → confirm next step.

## Flow B — Missing information
Customer query → required information missing → request clarification → customer provides information → continue within scope.

## Flow C — No system access
Customer asks for real-time status → assistant lacks data → state limitation → ask for relevant information or provide support channel.

## Flow D — Ambiguous query
Example: “My order is wrong” → do not guess → clarify whether item is wrong, damaged, missing, or quantity is incorrect.

## Flow E — Escalation
Sensitive/complex/unsupported request → explain limitation → recommend human support → provide safe next step.
